🎙️ ควบคุมการพูด

เสียงพูดใช้เสียงภาษาไทยที่มีใน Android/Chrome หากไม่มีเสียงไทย ให้ติดตั้งหรือเปิดใช้งาน Text-to-speech ภาษาไทยในการตั้งค่า Android

📱 วิธีนำขึ้น TikTok จาก Android

  1. นำโปรเจกต์นี้ไปติดตั้งบนโฮสต์ HTTPS เช่น Replit หรือ Render (ต้องตั้งค่า Environment Variables)
  2. เปิด URL ของเว็บนี้ใน Chrome บน Android แล้วเลือก “เพิ่มลงในหน้าจอหลัก”
  3. ทดลองปุ่มสร้างบทพูดและเสียงก่อน
  4. หากบัญชี TikTok มี LIVE แบบแชร์หน้าจอ ให้ทดลองแชร์หน้าจอโดยเปิดหน้า Overlay แยก และตรวจสอบว่าเสียงจากอุปกรณ์ถูกส่งเข้าไลฟ์จริงหรือไม่
  5. หาก TikTok ให้ RTMP URL/Stream Key ให้ใช้แอปสตรีม RTMP ที่เชื่อถือได้และรองรับ Android โดยใส่ข้อมูลจาก TikTok เท่านั้น

ข้อจำกัดสำคัญ: เว็บนี้เป็นรีโมตควบคุมและสร้างเสียง/บทพูด ไม่สามารถเปิด TikTok LIVE แทนบัญชีหรือสร้าง Stream Key ให้ได้ การแชร์หน้าจออาจไม่ส่งเสียง TTS เข้าไลฟ์ ขึ้นกับ TikTok และ Android รุ่น/การตั้งค่า ต้องทดสอบไลฟ์ส่วนตัวหรือผู้ชมจำกัดก่อน ระบบอ่านคอมเมนต์ TikTok อัตโนมัติยังไม่เปิดใช้ เพราะต้องมีการเชื่อมต่อที่ได้รับอนุญาต
